# Nguồn ảnh

Mọi ảnh **tải về** thư mục này, không hotlink CDN ngoài.

- Ảnh gốc đặt ở `public/images/_src/<nhóm>/`, chạy `npm run images` để sinh WebP + JPEG
  ở 3 mốc `480 / 960 / 1600` ra `public/images/<nhóm>/`.
- Chỉ dùng ảnh **Pexels / Unsplash** (license cho phép dùng thương mại).
- ⛔ **Không** lấy ảnh từ `dulich07.themeweb4s.com` — ảnh đó thuộc về trang mẫu.
